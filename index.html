Admin Deploy Guide

To accept submissions and view live data, you must deploy your backend:

  1. Create a Google Sheet named data for essay.
  2. Click on Extensions > Apps Script.
  3. Delete any code there and paste the contents of google_apps_script.js.
  4. Click Deploy > New deployment. Select type Web App. Set "Execute as" to Me and "Who has access" to Anyone.
  5. Copy the Web App URL and paste it in js/config.js.
  6. For GitHub Pages deployment, push these files to your GitHub repository and turn on Pages in your repo settings!
